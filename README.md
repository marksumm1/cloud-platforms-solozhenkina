**Автор:** Solozhenkina Elizaveta  
**Группа:** U4225  
**Учебный год:** 2026/2027

## Содержание

| Работа | Тема | Отчёт |
| --- | --- | --- |
| № 1 | Обзор Google Cloud и исследование основных сервисов | [lab1/lab1_report.md](lab1/lab1_report.md) |
| № 2 | Исследование Cloud Run | Будет добавлена |
| № 3 | Исследование Cloud Storage | Будет добавлена |
| № 4 | Инфраструктура MVP AI-приложения | Будет добавлена |

В первой лабораторной выполнены создание сервисного аккаунта, запуск Spot VM e2-micro, копирование и проверка файлов из Cloud Storage, эксперимент с заменой IAM-роли и анализ публичного доступа к изображениям. После работы VM и её загрузочный диск удалены.

## Структура

Каждая работа хранится в папке **labN**. Внутри находятся отчёт **labN_report.md** и иллюстрации **images**. Все пути к изображениям относительные, поэтому они работают на GitHub.

## Примечания

- **Date of finished** заполняется после защиты лабораторной работы у преподавателя.
- Не загружать в публичный репозиторий токены, пароли и файлы ключей сервисных аккаунтов.
- Скриншоты интерфейса Google Cloud включены исключительно для демонстрации учебных действий; права на сторонние элементы принадлежат их владельцам.
